# Sales Analysis Dashboard | Power BI & Excel

## 📌 Project Overview
This project focuses on analyzing sales data using **Microsoft Excel and Power BI** to identify sales trends, evaluate product performance, and understand customer and regional sales patterns. The interactive dashboard helps users explore business performance and make data-driven decisions.

## 🎯 Project Objectives
- Analyze overall sales performance and trends over time.
- Identify top-performing product categories and sub-categories.
- Compare sales across different regions, states, and cities.
- Understand customer segments and their contribution to sales.
- Evaluate sales distribution across different shipping modes.
- Present key business insights through an interactive dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data cleaning, data preparation, and initial exploration.
- **Microsoft Power BI:** Data visualization, dashboard development, and interactive analysis.
- **Power Query:** Data transformation and preparation, where applicable.

## 📂 Dataset Description
The dataset contains approximately 9,800 sales records with information about orders, customers, products, locations, and sales.

Key columns include:
- Order ID, Order Date, Ship Date
- Customer ID, Customer Name, Segment
- Country, State, City, Region, Postal Code
- Product ID, Product Name, Category, Sub-Category
- Ship Mode and Sales

## 📊 Dashboard Features
- **Sales Overview:** Summary of sales performance using KPI cards.
- **Sales Trends:** Analyze how sales change over time.
- **Category Analysis:** Compare sales across product categories and sub-categories.
- **Regional Analysis:** Identify locations contributing the most sales.
- **Customer Segment Analysis:** Compare sales across customer segments.
- **Shipping Analysis:** Understand sales distribution by shipping mode.
- **Interactive Filters:** Explore the data by date, region, category, and other available fields.

## 🔍 Business Questions Answered
1. What are the total sales?
2. How do sales change over time?
3. Which product categories generate the highest sales?
4. Which sub-categories contribute the most to sales?
5. Which regions and states have the highest sales?
6. Which cities contribute the most to overall sales?
7. Which customer segment generates the highest sales?
8. Which shipping mode is most commonly used?
9. Which products have the highest sales?
10. How does sales performance vary across different regions and product categories?

4. Refresh the data if required.
